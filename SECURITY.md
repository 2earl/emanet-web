# Security Policy

This repository contains emanet.dev, Emanet's public site and legal pages. It is public to read
but proprietary: see LICENSE.

## Reporting a vulnerability

Write to **iletisim@emanet.dev** with "Security" in the subject. The same contact is published at
<https://emanet.dev/.well-known/security.txt>. Please don't disclose it before it's fixed.

Include as much of the following as you can:

- affected endpoint, flow or component
- steps to reproduce or a proof of concept
- impact you believe it has

You will receive an acknowledgement after the report is reviewed.

## Scope

In scope: the code in this repository and its deployment. Sign-in and tokens are 2earl/login's;
the data and rules are 2earl/emanet-core's. The same address
takes reports for all of them.

Out of scope: denial-of-service through volumetric traffic, social engineering, and findings in
third-party services (Google, Cloudflare, GitHub).
